How I prioritise

There's always more to build than time to build it. These four questions help me decide what comes first.

Reach

How many customers have this problem?

If one customer asks, it can usually wait. If the same thing comes up across many accounts, it can't.

Customers asked for panel interviews almost every week, so that went first.

Revenue

Is a renewal or a new deal at risk?

If a customer might leave, or a sale is stuck, the request moves up.

A large prospect stalled on data-privacy questions, so privacy features moved up the list.

Activation

Is this stopping a customer from starting?

A customer who has paid but can't start using the product is one of the most urgent problems we can have.

We released brand-level access on the current system so a new customer could launch on time.

Reuse

Can we solve it with what we already have?

Before building something new, I check whether an existing feature already does the job.

One renewal request was solved by giving the right person access to a feature we already had.
